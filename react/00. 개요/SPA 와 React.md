# SPA (Single Page Application) 및 React 개요

## SPA (Single Page Application)

### 정의

SPA 는 사용자가 웹사이트를 방문했을 때 **하나의 페이지만** 표시하며, 모든 기능을 해당 페이지 내에서 제공하는 애플리케이션을 의미합니다.

웹사이트를 방문하면 하나의 HTML 파일만 전송되어 페이지가 렌더링되며, 이후에는 서버를 호출하기 위해 새 HTTP 요청을 보내지 않고 모든 상호작용이 발생하며 페이지가 유지됩니다.

### 주요 특징

- **로딩 속도 빠름**: 초기 로딩 후 추가 콘텐츠 로딩 없이 즉시 사용 가능
- **사용자 경험 향상**: 페이지 전환 시 로딩 화면 없이 부드러운 경험 제공
- **서버 요청 최소화**: AJAX, Fetch API 를 사용한 비동기 데이터 로딩으로 서버 부담 감소
- **로컬 저장소 활용**: LocalStorage, SessionStorage, Indexed API 등을 활용하여 데이터 저장

### SPA 의 예시

- React, Vue, Angular 와 같은 프론트엔드 프레임워크 기반 애플리케이션
- Google+, Facebook, Twitter, Amazon, Netflix 와 같은 현대적인 웹 애플리케이션

## React

### 정의

React 는 JavaScript 기반의 프론트엔드 웹 프레임워크로, Facebook 에 의해 2013 년 처음 공개되었습니다. 컴포네네 기반의 UI 빌드 도구를 제공합니다.

### 주요 장점

#### 1. 컴포넌트 기반 설계

- 재사용 가능한 컴포넌트로 코드를 구성할 수 있어 재사용성 및 유지보수가 용이
- 작은 기능 단위로 개발할 수 있어 개발 효율성 증가

#### 2. 가상 DOM(Virtual DOM)

- 실제 DOM 을 직접 조작하기보다 가상 DOM 으로 먼저 계산한 후 효율적으로 업데이트
- DOM 조작 최소화하여 성능 최적화

#### 3. JSX

- HTML 과 JavaScript 를 하나의 언어처럼 사용할 수 있도록 지원
- 코드 가독성 및 개발 효율성 향상

#### 4. 강력한 생태계

- React Community, NPM, 그리고 다양한 라이브러리 및 도구 지원
- React Router, Redux, Material-UI 등 풍부한 라이브러리 활용

#### 5. TypeScript 지원

- JavaScript 의 타입 안전성을 제공하여 오류 예방 및 개발 효율성 향상
- IDE 와의 완전한 통합 지원

#### 6. 핫 리프resco(Hot Reload)

- 개발 중 코드 변경 즉시 변경사항을 볼 수 있도록 지원
- 개발 과정에서의 효율성 및 피드백 속도 향상

#### 7. 큰 커뮤니티 지원

- 수천 명의 개발자가 참여하여 문서, 예제, 커뮤니티 지원이 잘 제공

### React 의 특징

- **컴포넌트 기반**: 작은 기능 단위로 코드를 구성할 수 있어 유지보수가 용이합니다
- **비동기 데이터 처리**: React 는 데이터의 동기적 및 비동기 처리 모두를 지원합니다
- **컴포넌트 재사용**: 컴포넌트를 다른 앱에 쉽게 재사용할 수 있습니다
- **가상 DOM**: 가상 DOM 을 사용하여 효율적인 렌더링을 제공합니다

### React 와 React-Native 의 차이

| 특징      | React                 | React-Native        |
| --------- | --------------------- | ------------------- |
| 주요 용도 | 웹 애플리케이션       | 모바일 애플리케이션 |
| 플랫폼    | 웹                    | iOS, Android        |
| 기술 스택 | JavaScript, HTML, CSS | React, JavaScript   |

### 결론

React 는 컴포넌트 기반 설계와 가상 DOM, 그리고 강력한 생태계를 통해 개발자에게 뛰어난 개발 경험과 효율성을 제공합니다. 이를 통해 대규모 웹 애플리케이션 구축에 적합하며, 지속적으로 발전하고 있는 프레임워크입니다.
